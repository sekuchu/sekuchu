## About

I'm a software developer interested in understanding how things work, from low-level programming and computer architecture to operating systems, embedded devices, and complete software systems.

I enjoy experimenting with different technologies, building practical projects, and expanding my knowledge through hands-on development.

My interests sit at the intersection of **applied computer science, systems engineering, and electronics**, with an emphasis on understanding the relationship between hardware and software.
